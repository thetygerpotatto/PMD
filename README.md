# Gramable: formal grammar interpreter in C

An interactive tool for defining a **formal grammar** G = (V, T, S, P) and then:
- **checking whether a word belongs** to the language generated by G, and
- **generating words** of the language (the first 10 derivations).

Written in plain C for a Discrete Mathematics course. **The data structures are hand-written**, with no external libraries:
- `d_string`: a dynamic, growable string with append, insert, delete, find and concatenate, all with manual `malloc`/`realloc` management.
- `set`: a dynamic set of `d_string` symbols used for the vocabulary and terminal symbols.
- `ruleset`: production rules (left side → right side).

Generation is a recursive derivation search with a **recursion limit** and a **branching limit**, so grammars with loops can't hang the program.

## Usage
```sh
cd Gramable
make            # builds bin/gramable and runs it
```
The program is menu-driven (in Spanish):
```
1 - Ingresar el vocabulario (V)        4 - Ingresar las reglas (P)
2 - Ingresar los símbolos terminales   5 - Probar una palabra
3 - Ingresar el símbolo inicial (S)    6 - Generar el lenguaje
7 - Menú de edición                    0 - Salir
```

## Structure
```
Gramable/src/gramable.c        # menus, derivation / generation logic
Gramable/src/ruleset.[ch]      # production rules
Gramable/src/utils/d_string.*  # dynamic string library
Gramable/src/utils/set.*       # dynamic set library
FiniteCoffe/                   # part 2: finite-state machine (C++) simulating a coffee vending machine
```

## FiniteCoffe
Part 2 of the same course project: a coffee vending machine modeled as a **finite-state automaton** in C++. States are balance ranges loaded from `states.txt`, and transitions are coin inputs.
